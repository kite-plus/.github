## 从一份内容开始

Kite Plus 是 Kite 及相关项目的开源组织。我们希望从写作到发布，让工具围绕你的内容工作。

**[Kite](https://github.com/kite-plus/kite)** 是我们的内容发布平台：用 Markdown 保存内容，在可视化后台编辑，构建静态站点，并通过 Git 管理和发布。Go 服务与内嵌 React 后台放在同一个程序里，让本地写作和内容管理衔接起来。

**写作 → 管理 → 构建 → 发布**

> Kite 正处于早期开发阶段。目前重点是写作、后台管理和 Git 发布；动态模式与插件仍在规划中。具体能力与进度请以项目文档和路线图为准。

## 接下来：Explore

我们计划构建 **Explore**，一个面向内容聚合与发现的平台，让创作与发布之后的内容有一个被发现的入口。Explore 目前处于规划阶段，尚未上线。

## 我们重视什么

- **内容可掌握**：优先使用易于读取、管理和迁移的内容格式。
- **工具有边界**：围绕清晰的问题构建工具，让上手和维护保持简单。
- **进展说清楚**：区分已实现能力与未来计划，让选择建立在真实状态上。
- **一起改进**：欢迎使用反馈、文档修正和围绕实际需求的贡献。

## 加入建设

**想开始使用？** 从 [Kite 中文文档](https://github.com/kite-plus/kite/blob/main/README.zh-CN.md) 了解安装方式、使用流程和当前限制。

**遇到问题或有新想法？** 请到对应项目的 Issues 中提交，附上使用版本、环境、复现步骤和预期行为。Kite 的反馈入口在 [这里](https://github.com/kite-plus/kite/issues)。

**想贡献代码或文档？** 先阅读目标项目的说明；较大的改动建议先用 Issue 讨论，再提交 Pull Request。许可证与贡献要求以各项目自身文件为准。
