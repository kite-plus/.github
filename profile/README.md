## Start with your content

Kite Plus is the open-source home of Kite and related projects. From writing to publishing, we want tools to work around your content.

**[Kite](https://github.com/kite-plus/kite)** is our content publishing platform: keep content in Markdown, edit it in a visual admin panel, build static sites, and manage and publish through Git. A Go server and embedded React admin panel ship in one program, connecting local writing with content management.

**Write → Manage → Build → Publish**

> Kite is in early development. The current focus is writing, admin tools, and Git publishing; dynamic mode and plugins remain planned. Check the project documentation and roadmap for current capabilities and progress.

## Next: Explore

We plan to build **Explore**, a platform for content aggregation and discovery, giving published content a place to be found. Explore is currently in planning and has not launched.

## What matters to us

- **Content you control**: favor formats that are easy to read, manage, and move.
- **Focused tools**: solve clear problems and keep setup and maintenance simple.
- **Clear progress**: distinguish shipped capabilities from future plans.
- **Shared improvement**: welcome feedback, documentation fixes, and contributions grounded in real needs.

## Build with us

**Ready to try it?** Read the [Kite documentation](https://github.com/kite-plus/kite/blob/main/README.md) for installation, workflows, and current limitations.

**Found a problem or have an idea?** Open an issue in the relevant project with your version, environment, reproduction steps, and expected behavior. For Kite, [start here](https://github.com/kite-plus/kite/issues).

**Want to contribute?** Read the target project's guidance first. Discuss larger changes in an issue before opening a pull request. Each project's own files define its license and contribution requirements.
