## 项目

### Kite

以 Markdown 为基础的内容发布平台。在浏览器里的后台写作，每篇文章都是归你所有的 Markdown 文件，可以发布为静态页面、运行在自己的服务器上，或者通过 Git 发布。Kite 仍处于早期开发阶段。

[代码仓库](https://github.com/kite-plus/kite) · [工作方式](https://github.com/kite-plus/kite/blob/main/README.zh-CN.md#工作方式) · [路线图](https://github.com/kite-plus/kite/blob/main/README.zh-CN.md#路线图)

### Explore

内容聚合与发现平台，汇集大家发布的内容，帮读者找到它们。Explore 仍在规划中，尚未上线。

[代码仓库](https://github.com/kite-plus/explore)

## 我们怎么做

- **开放格式优先**：内容保存在 Markdown 和 Git 里，你可以直接阅读、对比差异，也可以随时带走，不依赖我们。
- **选择可以改变**：内容存在哪里、以什么方式交付，是两个独立的决定。换托管平台，不应该意味着换工具。
- **设计先写成文档**：架构先在设计文档中确定，再写代码；与设计文档冲突的改动，先改文档。
- **如实标注进度**：已经可用的和仍在规划的，在代码和文档里都分开标明。
